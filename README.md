# Curso_Fundamentos_da_Programacao_JavaScript_Hora_de_Codar
Curso de Fundamentos da Programação com JavaScript, abordando operadores, laços, arrays, funções, Promises, Async/Await, objetos e manipulação do DOM. Inclui exercícios práticos e um projeto completo de calculadora, preparando o aluno para avançar no desenvolvimento web.

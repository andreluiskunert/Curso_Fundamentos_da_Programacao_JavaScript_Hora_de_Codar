# 📚 Curso: Fundamentos da Programação

Este curso oferece uma introdução completa à **programação com JavaScript**, abordando desde conceitos básicos até técnicas intermediárias e boas práticas.

O conteúdo é apresentado de forma passo a passo, permitindo desenvolver habilidades essenciais para criar **programas funcionais, interativos e aplicações web**.

---

## 🎯 Objetivos do Curso

* Compreender os fundamentos da programação.
* Aprender a linguagem **JavaScript**.
* Desenvolver lógica de programação.
* Trabalhar com estruturas de repetição e decisão.
* Manipular arrays e objetos.
* Criar e utilizar funções.
* Compreender programação assíncrona.
* Manipular elementos de páginas web através do DOM.
* Desenvolver projetos práticos.
* Criar uma calculadora completa utilizando JavaScript.

---

# 📖 Conteúdo do Curso

## 🔹 Módulo 1 — Fundamentos da Programação com JavaScript

### ⚙️ Setup Inicial

Configuração do ambiente de desenvolvimento necessário para começar a programar em JavaScript.

### ➕ Operadores

Introdução aos principais operadores:

* Operadores aritméticos
* Operadores lógicos
* Operadores de comparação
* Operadores de atribuição

### 🚀 Avançando nos Operadores

Exploração de operadores avançados e técnicas para simplificar expressões e tornar o código mais eficiente.

### 🔄 Laços — Parte 1 e Parte 2

Estudo das estruturas de repetição utilizadas para executar um determinado bloco de código várias vezes.

Principais estruturas:

* `for`
* `while`
* `do...while`

### 📦 Arrays

Criação e manipulação de listas de dados utilizando arrays.

Conteúdos:

* Criação de arrays
* Índices
* Acesso aos elementos
* Manipulação de dados
* Métodos de arrays
* Remoção de elementos

### 🧩 Funções

Criação e utilização de funções em JavaScript.

Conteúdos:

* Funções básicas
* Parâmetros
* Retorno de valores
* Funções avançadas
* Promises
* Programação assíncrona
* `async/await`

### 🏋️ Exercícios Práticos

Aplicação dos conceitos estudados através de exercícios envolvendo:

* Arrays
* Funções
* Operadores
* Estruturas de repetição
* Operações assíncronas

### 🗂️ Objetos

Introdução às estruturas de dados mais complexas utilizando objetos JavaScript.

### 🌐 DOM e Manipulação do DOM

Introdução ao **Document Object Model (DOM)** e sua utilização para interagir com páginas HTML.

Possibilitando:

* Alterar elementos HTML
* Modificar conteúdos
* Manipular atributos
* Criar elementos dinamicamente
* Responder a eventos
* Criar páginas web interativas

### 💡 Análise e Desenvolvimento Profissional

Orientações sobre:

* Boas práticas de programação
* Análise de problemas
* Organização do código
* Resolução de problemas
* Evolução profissional
* Como se tornar um programador passo a passo
